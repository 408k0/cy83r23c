# 06-GRC-y-Continuidad
- Gobernanza, Riesgo y Cumplimiento (GRC): es un enfoque para alinear objetivos, gestionar amenazas y cumplir normas. Un GRC continuo busca mantener activos los controles y evidencias en el día a día, no solo antes de una auditoría.
- Continuidad de negocio: mantener o recuperar funciones críticas tras una interrupción.
- Temas: Análisis de impacto al negocio (BIA), planes de recuperación ante desastres (DRP), matrices de riesgos y políticas de seguridad.
