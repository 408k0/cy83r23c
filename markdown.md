# Sintaxis Markdown

La nomenclatura (o sintaxis) de Markdown usa símbolos sencillos en texto plano para dar formato rápido a documentos

## Encabezados
- "#" Título 1 hasta "######" Título 6 (Sin comillas)

## Énfasis y formato de texto
- Cursiva: *texto* o _texto_
- Negrita: **texto** o __texto__
- Negrita y cursiva: ***texto*** o ___texto___
- Tachado: ~~texto~~ (sintaxis extendida)
- Escapar caracteres especiales: \* o \# con barra invertida \ 

## Listas
- Sin orden: -, * o + seguido de espacio
- Ordenadas: 1., 2., etc.
- Tareas: - [ ] Pendiente o - [x] Hecho (sintaxis extendida) 

## Enlaces e imágenes
- Enlace: [Texto visible](https://ejemplo.com)
- Imagen: ![Texto alternativo](https://img.shields.io/badge/build-passing-brightgreen?style=for-the-badge)
    - **Nota:**
`Evitar el error "Error Fetching Resource" ocurre porque GitHub intenta descargar y almacenar en caché la imagen a través de sus propios servidores (://githubusercontent.com), y plataformas como Freepik o Flaticon bloquean este acceso directo para evitar el hotlinking (consumo de ancho de banda externo).`

## Citas, código y separadores
- Cita en bloque: > Texto citado (usa >> para citas anidadas)
- Código en línea: `código`
- Bloque de código: tres comillas invertidas ``` (puedes indicar el lenguaje al inicio) o cuatro espacios al comienzo de la línea
- Línea horizontal: ---, *** o ___ en una línea sola 

## Tablas (sintaxis extendida)
- Usa barras verticales | y guiones - para separar columnas y encabezados:

| Columna 1 | Columna 2 |
| --- | --- |
| Dato A | Dato B |
