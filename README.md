# Ciberseguridad
## 01-Sistemas-y-Arquitectura
   Temas: Arquitectura de Computadoras, Sistemas Operativos y Administración de Sistemas Operativos.
   Contenido: Scripts de automatización en Bash/PowerShell, gestión de permisos, configuración de redes locales y análisis de procesos.
## 02-Hardening-y-Seguridad-SO
	- Temas: Seguridad de Sistemas Operativos.
	- Contenido: Guías de bastión (hardening) en Linux/Windows, configuración de firewalls (UFW/iptables), políticas de grupo (GPO) y auditorías de sistema.
## 03-Criptografia-Aplicada
	- Temas: Fundamentos de Criptografía.
	- Contenido: Implementaciones de cifrado simétrico/asimétrico, gestión de certificados digitales (PKI), análisis de funciones hash y protocolos seguros.
## 04-Seguridad-Ofensiva-y-Defensiva
	- Temas: Introducción a Ciberseguridad y Técnicas de Seguridad Informática I.
	- Contenido: Reportes de análisis de vulnerabilidades, prácticas de pentesting básico (Nmap, Metasploit), análisis de tráfico (Wireshark) y mitigación de ataques.
## 05-Seguridad-Movil
	- Temas: Seguridad en Dispositivos Móviles.
	- Contenido: Análisis estático/dinámico de APKs, evaluación de permisos en Android/iOS y pruebas de seguridad en aplicaciones móviles.
## 06-GRC-y-Continuidad
	- Temas: Gestión de la Continuidad del Negocio.
	- Contenido: Análisis de impacto al negocio (BIA), planes de recuperación ante desastres (DRP), matrices de riesgos y políticas de seguridad.
